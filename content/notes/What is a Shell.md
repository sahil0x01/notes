The program that reads commands and runs them is called as a **shell** [[Learn Linux]]

> An [operating system](https://en.wikipedia.org/wiki/Operating_system "Operating system") **shell** is a [computer program](https://en.wikipedia.org/wiki/Computer_program "Computer program") that provides relatively broad and direct access to the system on which it runs. The term _shell_ refers to how it is a relatively thin [layer](https://en.wikipedia.org/wiki/Abstraction_layer "Abstraction layer") around an operating system [wiki](https://en.wikipedia.org/wiki/Shell_(computing)#:~:text=An,system,-%2E%5B1)


Shells are usually called as REPLs. REPL stands for:
- **R**ead the command you type
- **E**valuate that command, usually by running _other_ programs on your computer
- **P**rint the output of the command
- **L**oop: Give you a new prompt so you can do it again
