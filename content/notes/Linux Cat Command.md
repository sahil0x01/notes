The [`cat` command](https://www.gnu.org/software/coreutils/manual/html_node/cat-invocation.html) is used to view the contents of a file. It's short for "concatenate," which is a fancy way of saying "put things together." It can feel like a confusing name if you're using the `cat` command to view a single file, but it makes more sense when you're using it to view multiple files at once [in](https://www.boot.dev/lessons/6ad3a904-7e19-4511-859e-cf78472db0aa#:~:text=Command-,The,once) [[Learn Linux]]
