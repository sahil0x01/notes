The output of `pwd` is a _filepath_. A filepath is a string that describes the location of a file or directory on your computer. Here on Boot.dev, your home directory is always `/home/user` [in](https://www.boot.dev/lessons/f5f6762e-9736-4d2f-aaff-423088dbbf47#:~:text=The%20output%20of%20pwd%20is%20a%20filepath%2E%20A%20filepath%20is%20a%20string%20that%20describes%20the%20location%20of%20a%20file%20or%20directory%20on%20your%20computer%2E%20Here%20on%20Boot%2Edev%2C%20your%20home%20directory%20is%20always%20%2Fhome%2Fuser%2E) [[Learn Linux]]


The [`ls` ("list") command](https://www.gnu.org/software/coreutils/manual/html_node/ls-invocation.html) prints the contents of a directory. To list a different directory without moving into it, put its path after `ls`: `ls DIRECTORY` [in](https://www.boot.dev/lessons/f5f6762e-9736-4d2f-aaff-423088dbbf47#:~:text=The%20ls%20%28%22list%22%29%20command%20prints%20the%20contents%20of%20a%20directory%2E%20To%20list%20a%20different%20directory%20without%20moving%20into%20it%2C%20put%20its%20path%20after%20ls%3A%20ls%20DIRECTORY%2E) [[Learn Linux]]
