JavaScript uses a single [`Number`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number) type for both integer and floating types [in](https://www.boot.dev/lessons/fdc1ba36-43a1-4bdc-b70b-c2ce02cdfc08#:~:text=JavaScript%20uses%20a%20single%20Number%20type%20for%20both) [[JavaScript|source]]
```javascript
let x = 2; // this is a number
x = 5.69; // this is also a number
x = -5.42; // yup, still a number
```
